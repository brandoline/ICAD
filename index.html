02 — Type

Tipografia

Noto Serif Display para personalidade em títulos. Open Sans para clareza em textos de interface e corpo.

04 — Navegação

Links

Links de texto usam rosa sobre marrom para contraste calmo; links utilitários usam roxo com movimento no hover.
